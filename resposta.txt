Passo a passo: publicar matéria manualmente

1. Configure Supabase (importante)
- Abra https://supabase.com → seu projeto → SQL Editor → New query
- Cole o conteúdo de `supabase/schema.sql` deste projeto e Execute
- Authentication → Users → Add user (crie e-mail + senha)

2. Configure .env.local
Tem a URL e ANON_KEY. Só falta `GEMINI_API_KEY` (opcional p/ IA). Já deixei configurado.

3. Iniciar o site
`npm run dev` → http://localhost:3000

4. Entrar no painel
http://localhost:3000/admin → redireciona p/ /admin/login
Login: e-mail/senha criados no Supabase

5. Criar matéria manual
Painel → "+ Nova matéria" (ou "Escrever manualmente")
Preencher:
- Título (obrigatório)
- Linha fina (resumo)
- Editoria (dropdown)
- Tags (separadas por vírgula)
- Autor (padrão Redação)
- Capa: enviar imagem (upload p/ Supabase bucket covers) OU colar URL
- Descrição da imagem (alt) — acessibilidade
- Endereço /materia/ (slug) — vazio gera automático
- "Destacar na home" se quiser como destaque
- Corpo: editor com botões H2, Negrito, Itálico, Citação, Listas, Link
- "Salvar rascunho" ou "Salvar e publicar"

6. Publicada
Ao publicar, aparece link "Ver no site". Matérias publicadas vão p/ home, página da editoria e busca.
