Passo a passo: publicar matéria manualmente

1. Configurar Supabase
   - Acesse https://supabase.com → seu projeto → SQL Editor → New query
   - Cole todo o conteúdo de supabase/schema.sql e clique em Executar
   - Vá em Authentication → Users → Add user e crie e-mail + senha

2. .env.local
   Já tem NEXT_PUBLIC_SUPABASE_URL e NEXT_PUBLIC_SUPABASE_ANON_KEY. Falta só GEMINI_API_KEY (opcional p/ IA).

3. Rodar
   npm run dev
   http://localhost:3000

4. Entrar no painel
   http://localhost:3000/admin (redireciona p/ login)
   Use e-mail/senha criado no Supabase

5. Criar matéria manual
   Painel → + Nova matéria → aba Escrever manualmente

   Campos:
   - Título (obrigatório)
   - Linha fina (resumo curto)
   - Editoria
   - Tags (separadas por vírgula)
   - Autor (padrão Redação)
   - Capa: Enviar imagem (bucket covers) OU colar URL
   - Descrição da imagem (alt)
   - URL da matéria (/materia/) – vazio gera automático
   - Destacar na home
   - Corpo: H2, Negrito, Itálico, Citação, Listas, Link

   Botões:
   - Salvar rascunho (só no painel)
   - Salvar e publicar (vai ao site)

6. Conferir
   Após publicar, clique Ver no site ou acesse /materia/SLUG

Obs.: se não rodou o SQL, aparece 'Configuração pendente'. Rode e recarregue.
